# druzhba-cdn

Фотографии корнеров фудхолла «Дружба-Москва» для сайта druzhba-moscow.ru (Tilda).
Публикуются через GitHub Pages: https://neonsky3214-commits.github.io/druzhba-cdn/

- `corners/<код>.jpg` — витрина корнера, 1600×1200 (карточка корнера); `<код>-800.jpg` — 800×600.
- `more/<код>.jpg` — блок «А ещё в «Дружбе»», 960×720.
- `logos/<код>.jpg` — логотипы корнеров без официальных файлов (FAT, «Старый Стамбул», «Турецкая пекарня», «Самарканд», «Мидийное место»), 600×600. Собраны из букв вывесок на фото 07.10.2026 (скрипт `tools/sign_logos.py` в проекте сайта); знак «Мидийного места» — иконка их приложения в App Store.
- `kitchen/<код>.jpg` — тарелки раздела «Кухня», 900×900. Фото с Unsplash (Unsplash License, бесплатно для коммерческого использования): thai — Jamie Trinh, japan — Jakub Dziubak, china — Orijit Chatterjee, russia — Catherine, mussels — Cathrine Skovly, beer — Bohdan Stocek. `corners/ramen.jpg` — то же фото, что china (своего фото «Рамен&Вок» пока нет).
- `brand/druzhba-orange.png` — оранжевый логотип фудхолла для шапки сайта (из `_-_Lowres.png` Tilda, поля как у белого).
- `plan/floor-2.jpg` — схема 2 этажа ТДЦ «Аркадия» для интерактивной схемы (обрезка 120,100–1240,2032 исходника 1255×2048; зоны корнеров на сайте заданы в координатах исходника).

Съёмка 07.10.2026, ретушь: свет и цвет — Nano Banana / тоновые кривые, мелкий текст (меню, вывески) — с оригинала.
